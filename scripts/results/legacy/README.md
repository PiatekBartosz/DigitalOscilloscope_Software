# Wyniki legacy

Katalog zawiera pomocnicze pliki pomiarowe typu `debug` oraz kopie kontrolne
oznaczone przyrostkiem `_check`. Nie są używane przez GUI ani przez skrypty
generujące aktualne wykresy i tabele pracy. Zachowano je wyłącznie jako
archiwum, aby nie mieszać ich z kompletem danych wykorzystanym w rozdziale 7.
